## Port to Server

If the user asks to move their Claude setup to a server, run 24/7, 
transfer agents to cloud, or set up remote access — use the 
port-to-server skill.

Key things to tell the user:
- Their computer does not need to stay on once setup is complete
- SSH access to the server must be configured before running the skill
- Telegram bots and cron tasks will run continuously on the server
- They can SSH back in at any time to update skills or agents

Trigger: "port to server", "run 24/7", "move to cloud", 
"transfer my setup", "set up remote server"

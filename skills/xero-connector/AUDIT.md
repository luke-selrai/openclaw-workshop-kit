## Map

- **Job:** install Xero's official MCP server for a non-technical owner, hands-off. Claude
  drives the developer portal, creates a Custom Connection, ticks scopes, captures the
  Client ID and Secret, smoke-tests them, merges the MCP entry, and verifies with a real
  tool call. Then it operates the connection day to day.
- **Inputs:** the user's country, organisation name and cost consent; their own browser
  sign-in; the Xero developer portal DOM; `~/.claude.json` (read for an existing entry).
  Nothing else — no env vars, no server, no control pack.
- **Outputs:** an `mcpServers.xero` (or `mcpServers."xero-<orgslug>"`) block in
  `~/.claude.json` carrying `XERO_CLIENT_ID` / `XERO_CLIENT_SECRET`, a timestamped backup
  of the previous config, and — in Phase 2 — Xero reads plus DRAFT-only writes.
- **Depends on:** a house connector doctrine for comms, credentials and browser lanes,
  followed when it is installed beside this skill and not required when it is not, matching
  what SKILL.md actually says; the installed `@xeroapi/xero-mcp-server` (v0.0.17,
  51 tools) as the source of truth for tool names and scopes; browser lanes (Claude native
  → `agent-browser` → Playwright MCP per `references/playwright-fallback.md`); on this Mac
  only, the four `~/bin` launchers and their clearance ritual.
- **Write authority:** **NONE by default beyond Xero drafts.** Invoices, bills, quotes and
  credit notes create as DRAFT and are never auto-authorised or auto-sent; every write is
  re-read with the matching `list-*` and diffed. The connector cannot delete accounting
  records (no delete tool exists except payroll `delete-timesheet`), cannot reconcile bank
  transactions, and cannot file BAS or VAT. Card details are never entered by Claude. The
  gated `~/bin` launchers are fail-closed and grant nothing without a fresh clearance.
- **Entry points:** `SKILL.md` (Phase 0 → hand-off, then the operating rules);
  `references/tool-catalog.md` (51 tools grouped read/write/payroll);
  `references/playwright-fallback.md` (lane-3 verbatim recipe); `tests/` (the suite).
  No scripts — the installer steps are inline bash the session runs.
- **Location note:** cold skill, real directory (not a symlink). There is no hot
  `~/.claude/skills/xero-connector/`.

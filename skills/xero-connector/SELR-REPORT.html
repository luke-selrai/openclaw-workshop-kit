What it is for: install Xero's official MCP server for a non-technical owner, hands-off. Claude drives the developer portal, creates a Custom Connection, ticks scopes, captures the Client ID and Secret, smoke-tests them, merges the MCP entry, and verifies with a real tool call. Then it operates the connection day to day.

Write authority: NONE by default beyond Xero drafts. Invoices, bills, quotes and credit notes create as DRAFT and are never auto-authorised or auto-sent; every write is re-read with the matching list-* and diffed. The connector cannot delete accounting records (no delete tool exists except payroll delete-timesheet), cannot reconcile bank transactions, and cannot file BAS or VAT. Card details are never entered by Claude. The gated launchers are fail-closed and grant nothing without a fresh clearance.
